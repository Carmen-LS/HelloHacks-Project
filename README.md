# wellquest

Hackathon prototype for a healthy-aging app focused on UBC and West Point Grey.

This version only includes:

1. Signup that stores basic preferences
2. Recommendations from that signup
3. A filterable activity list (gym, sports, outdoors)
4. A map of nearby gyms, community centres, courts, and parks

The name is a placeholder and can change later.

```bash
npm install
npm run dev
```
